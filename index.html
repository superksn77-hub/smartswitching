🤖 Ollama AI 설정
🛠 문제 해결 / 설치 가이드
1️⃣ Ollama 설치

ollama.com/download 에서 다운로드 후 설치하세요.

2️⃣ 모델 다운로드

터미널(CMD / PowerShell / Terminal)에서:

ollama pull llama3.2

추천 모델: llama3.2 (빠름, 2GB) · qwen2.5 (한국어 우수) · gemma2:2b (매우 빠름)

3️⃣ ⚠ 가장 흔한 문제: CORS 차단

브라우저가 보안 정책으로 localhost:11434 요청을 차단합니다. OLLAMA_ORIGINS 환경변수를 설정해야 합니다.

🪟 Windows
  1. 작업 표시줄의 Ollama 아이콘 우클릭 → Quit으로 종료
  2. 시스템 환경변수 편집:
    시작 → "환경 변수" 검색 → 시스템 속성 → 환경 변수
  3. 사용자 변수 → 새로 만들기
    변수 이름: OLLAMA_ORIGINS
    변수 값: *
  4. 확인 후 Ollama 재시작
🍎 macOS / 🐧 Linux

터미널에서 Ollama 종료 후:

OLLAMA_ORIGINS=* ollama serve

영구 설정: ~/.zshrc 또는 ~/.bashrc에 export OLLAMA_ORIGINS=* 추가

4️⃣ Ollama 실행 확인

브라우저에서 http://localhost:11434 접속 시 Ollama is running 메시지가 보여야 합니다.
